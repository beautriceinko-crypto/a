# Liquid Glass iPhone Launcher

A responsive iPhone-style launcher prototype built with vanilla HTML, CSS and JavaScript.

## Features
- Dynamic animated glassmorphism/liquid-glass surfaces
- Live clock
- iPhone-inspired app grid and dock
- Touch/click interactions with glass feedback
- Focus mode
- Pointer tilt and mobile device-orientation parallax
- Responsive phone-sized layout

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages.

> This is a web launcher prototype, not an actual replacement for the iOS home screen.
